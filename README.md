# Portfolio Site

Minimal, modern portfolio website with a greyish aesthetic and subtle animations.

## Tech Stack

- **Astro** - Static site framework
- **Vue 3** - Interactive components
- **Tailwind CSS** - Styling
- **p5.js** - Canvas effects
- **motion-v** - Animations
- **TypeScript** - Type safety

## Setup

```bash
# Install dependencies
bun install

# Start dev server
bun dev

# Build for production
bun build

# Preview production build
bun preview
```
